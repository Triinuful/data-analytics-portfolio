# Data Analytics Portfolio

Welcome! This repository contains my data analytics projects using Python, Power BI, and SQL.

## Project 1: VIC International Student Numbers Analysis between 2005-2026 May
**Overview:** Analysis of international students numbers studying in VIC, Australia via student visa between 2005-2026 May.
Closer look into 5 highest number of international student countries' trends, to see if there are any underlying trends or patterns.

**Action:** Tidied and combined the smaller datasets into a master table, and created visualisations showing any findings.

**Tools used:** Plotly, Glob and Pandas Python libraries.

**Notebook:** https://www.kaggle.com/datasets/triinulepp/vic-internat 

**Data source:** Australian Government Department of Education, International student numbers by country, state and territory. Source data is derived from PRISMS. Used under the Creative Commons Attribution 4.0 International (CC BY 4.0) licence. © Commonwealth of Australia.
https://www.education.gov.au/international-education-data-and-research/international-student-numbers-country-state-and-territory
